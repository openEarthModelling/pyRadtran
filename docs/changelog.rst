Changelog
=========

Please see the `CHANGELOG.md <https://github.com/openEarthModelling/pyRadtran/blob/main/CHANGELOG.md>`_ file in the repository for the full project changelog.

Release History
---------------

* **v0.1.0** (2026-05-12): Initial release
    * Scene builder API with fluent interface
    * Runner for executing libRadtran simulations
    * Aerosol model support (OPAC presets, custom OPAC, external files)
    * Composite aerosol with Mie scattering integration
    * Convenience functions for common simulation configurations
    * Full test suite with pytest
    * Documentation with Sphinx
